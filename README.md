# Tone Tutor — 楽譜読譜トレーナー

楽譜に表示された音符の名前を素早く答える、読譜トレーニング Web アプリです。

## 機能

- **3 つの音部記号** — ト音記号 / ヘ音記号 / ハ音記号
- **全 12 音出題** — 自然音 + シャープ音（C〜B + C#/D#/F#/G#/A#）
- **3 つの練習モード**
  - タイムアタック（60 秒で何問正解できるか）
  - 連続正解（ミスするまで続く）
  - 通常（制限なし）
- **3 種類の入力方法**（設定で組み合わせ可能）
  - 選択肢ボタン（12 音）
  - 画面鍵盤クリック
  - MIDI キーボード（Web MIDI API、Chrome / Edge）
- **音名表記の切替** — ドレミ（固定ド）/ C・D・E
- **進捗グラフ** — 直近 20 セッションの正答率折れ線 + 音別ヒートマップ
- **誤答復習** — 前回間違えた音だけを集中練習
- **参照チャート** — 記号ごとの全音符一覧

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開いてください。

## テスト

```bash
npm test
```
